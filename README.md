# Katalog Produk

Aplikasi desktop sederhana untuk mengelola data katalog produk (Tambah, Lihat, Edit, dan Hapus) yang dibangun menggunakan **Apache NetBeans (JavaFX)**, **SceneBuilder**, dan **SQLite**.

## Fitur
- Input Nama Produk, Harga (Rp), dan pilihan Foto Produk (roti.png, susu.png, kopi.png).
- Penyimpanan dan tampilan data katalog produk secara otomatis menggunakan database SQLite.
- Fitur Edit dan Hapus data produk langsung dari kartu katalog.
- Penghitungan total jumlah produk secara otomatis.
- Handling error jika input kosong atau harga bukan berupa angka bulat positif.

## Teknologi yang Digunakan
- **Apache NetBeans (JavaFX)**
- **SceneBuilder (FXML & CSS)**
- **SQLite**

## Demo aplikasi

1. Buka Aplikasi
- Jalankan aplikasi Katalog Produk di perangkat Anda.

2. Masukkan Data Produk
- Ketikkan nama produk pada kolom **Nama produk** (contoh: Roti Cokelat).
- Ketikkan harga produk pada kolom **Harga (Rp)** menggunakan angka bulat (contoh: 10000).
